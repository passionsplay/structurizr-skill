## Observations

- Every baseline failure was invalid or incomplete DSL that the agent never checked. The skill's main value for this model is the validate loop plus the DSL rules, not knowledge of C4.
- Isolation leak: the baseline agent found and ran a Java install on the host (`~/.local/share/mise/installs/java`). The temp work dir hides the repo, not the machine. Running trials in a container would close this.
- Grader fixes made after this run: quality metrics are now blank for workspaces that do not validate (they previously read as 0% coverage and 1 finding), and `transcript_validate_mentions`, which counted the word, became `validate_calls`, which counts commands. Pass/fail is unaffected. Corrected metrics for the affected trials: `create-webapp` baseline `validate_calls=0`; `component-store` baseline `inspect_findings=17 tech_coverage_pct=0 validate_calls=6`; `component-store` skill `inspect_findings=2 tech_coverage_pct=100 validate_calls=1`.
